# ☕ TL Coffee — React App

## 📁 Cấu trúc
```
tl-coffee/
├── public/index.html
├── src/
│   ├── App.jsx
│   ├── index.js / index.css
│   ├── context/CartContext.jsx     ← Giỏ hàng toàn cục
│   ├── data/menuData.js            ← Toàn bộ menu + tin tức
│   ├── components/
│   │   ├── Navbar.jsx / .css
│   │   ├── CartSidebar.jsx / .css  ← Giỏ hàng trượt
│   │   ├── ProductCard.jsx / .css  ← Card sản phẩm
│   │   ├── NewsCard.jsx / .css     ← Card tin tức + modal
│   │   └── OrderModal.jsx / .css   ← Form đặt hàng + xác nhận
│   └── pages/
│       ├── Home.jsx                ← Trang chính
│       └── Home.css
└── package.json
```

## 🚀 Cách chạy

```bash
cd tl-coffee
npm install
npm start
```

Truy cập: http://localhost:3000

## ✨ Tính năng
- 6 danh mục menu, 24 món với mô tả chi tiết
- Giỏ hàng trượt từ bên phải
- Form đặt hàng online + xác nhận đơn
- 6 bài tin tức có thể đọc đầy đủ
- Banner khuyến mãi Mua 2 Tặng 1
- Thông tin liên hệ + bản đồ
- Responsive mobile
